# Reference excerpts

These MP3 files are 6-second excerpts of the
[Salamander Grand Piano V3](https://archive.org/details/SalamanderGrandPianoV3)
samples (Yamaha C5) by **Alexander Holm**, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

Changes: the stereo OGG samples (as distributed in the `@audio-samples/piano-velocity*`
npm packages) were mixed to mono as (L+R)/2, trimmed to the first 6 seconds and
re-encoded as 80 kbit/s MP3. File names use `s` for sharps, e.g. `Fs4v10.mp3`
is F#4 from velocity layer 10 of 16.

They are used only by the A/B comparison on the web page. The FM synthesiser
itself contains no samples.
